# 背多分

无需安装依赖，直接打开 index.html。也可以在此目录执行 `python3 -m http.server 8000` 后在浏览器访问。

词库按照用户提供的 12 页扫描 PDF 粗体词人工整理，为新版八年级上册 Unit 1–8。中文采用便于练习的简释，音标采用简化展示。data.js 可供逐词复核和调整。

正确率按首次答对计算；答错后可以继续尝试。掌握数按单元去重保存，答错会取消对应词的掌握状态。浏览器清理本地数据会重置进度。朗读依赖浏览器 speechSynthesis 和设备可用英语语音。

检查：JavaScript 语法、320 条词库结构通过。浏览器自动化未完成（环境缺少 Chromium）。
